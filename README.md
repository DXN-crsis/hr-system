# نظام إدارة الموارد البشرية

برنامج ويندوز بالعربي لإدارة بيانات الموظفين: لوحة معلومات وتدقيق للبيانات، قائمة موظفين مع بحث وتصفية، استمارة كاملة تحسب سنوات الخدمة تلقائياً، استيراد وتصدير Excel وWord، ونسخ احتياطي.
